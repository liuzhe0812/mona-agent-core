# Mona Web UI 组件合同

本文件把[设计系统](./DESIGN.zh-CN.md)落实为正式页面可复用的组件级尺寸、形状和状态合同。这里的“组件”指可见层和交互角色，不要求引入 React/Vue 或额外运行时；当前原生 HTML/DOM 通过共享 class 与 Token 复用同一合同。

## 1. 通用状态

每个交互组件在实际需要时必须覆盖：默认、hover、pressed、focus-visible、disabled、loading、selected、error。状态不得改变控件外框尺寸或标签位置。

- hover：`--surface-hover`，时长 `--motion-hover`。
- pressed：普通动作可缩放到 `.98`，不作用于拖动分隔条或数据图元。
- focus：2px `--focus-ring` + 2px offset；输入可使用 soft ring。
- disabled：保留布局和当前值，降低透明度，禁止激活。
- error：使用 `--status-danger`，不能只用颜色隐藏错误文本。

## 2. 动作

| 角色 | 高度 | 字号/字重 | 外框 | 用途 |
| --- | ---: | --- | --- | --- |
| `.primary` | 36px | 13/500 | 胶囊、强调底色 | 保存、连接、主要提交 |
| `.secondary` | 36px | 13/500 | 胶囊、1px 边框 | 取消、次级操作 |
| `.text-button` | 32px | 12/500 | 胶囊 hover、静止透明 | 刷新、轻量操作 |
| `.icon-button` | 32×32px | 图标 18px | 胶囊 | 无持久文字的动作 |
| `.send` | 34×34px | 图标 20px | 圆形；主输入器使用发送专属蓝色 | 发送任务 |

同一页面最多一个最强主要动作。危险操作保持中性外框并使用危险前景；需要确认时进入确认流程，不把整个设置页染红。图标按钮至少有 `aria-label`。

## 3. 表单控件

| 角色 | 尺寸 | 外框 | 说明 |
| --- | --- | --- | --- |
| 单行 Input / Select | 36px 默认；32/40px 为登记档 | 胶囊、1px 边框 | 使用统一 placeholder、focus 和 error 角色 |
| Textarea | 内容决定高度 | 8px、1px 边框 | 永远不是胶囊 |
| Checkbox | 原生尺寸 | 与标签同行 | 标签承担可点区域，不伪装 Switch |
| `.model-switch` | 40×24px，thumb 16px | 胶囊轨道 | 仅布尔启停；选中轨道使用主题语义色 |
| 分段单选 `.theme-modes` | 32px track | 胶囊 track/option | 原生 radio 语义，方向键可切换 |

表单字段标签 13px，辅助说明 12px。发生校验错误时保留错误空间并给出可执行文案。保存期间阻止重复提交；凭据不回显到浏览器存储。

## 4. Dialog、搜索与浮层

- 普通 Dialog：最大约 460px；供应商表单约 560px；视口 gutter 16px。
- 容器：12px 圆角、1px 边框、16px 内边距、无普通投影。
- 标题：18px/500；说明和字段：13px。
- Footer：右对齐，按钮高 36px，间距 8px。
- 可自由关闭的表单：Footer Cancel + Esc +遮罩；禁止同时增加右上角 ×。
- 搜索：输入区与结果区分隔；结果行高 36px、8px 内层圆角。空结果说明原因，不显示假记录。
- 关闭后恢复触发元素焦点；Dialog 内的错误和 loading 不改变宽度。

## 5. 主导航和侧栏

- 品牌行、新建任务和普通导航高 36px；图标 18px。
- 项目行高 36px，文件夹图标与项目名使用次级文字色；右侧保留操作菜单和项目内新建任务，不放文件浏览按钮。项目任务缩进并紧随其下，普通任务单独成组，导航区统一滚动。
- 项目区的添加操作按宿主能力使用名称表单或原生文件夹选择器；运行时不可用时禁用并说明原因，取消不改变项目列表或输入草稿。
- 会话行基线 32px，标题 13px，右侧相对时间 12px；选中与 hover 使用语义表面。每组先显示五条，按组展开更多。
- 默认侧栏 264px，可调偏好 208–460px；分隔条是 `separator`，键盘方向键每次 16px，Home/End 到当前边界，双击恢复默认。实际宽度与偏好分离：窗口变窄时临时收缩，不覆盖已保存偏好。
- 任务搜索使用弹窗，不使用常驻输入框。
- 窄屏变抽屉并隐藏分隔条；抽屉内保持键盘焦点，Escape/遮罩关闭后返回切换按钮。打开右侧模态面板会关闭导航抽屉，背景不可交互状态按所属浮层统一管理，不恢复过期快照。

## 6. 首页和聊天

### 新任务

空会话将 Mona 标识与标题、同一个任务输入器作为一组居中。标识 34px，标题 26px/500，窄屏为 24px；不显示宣传说明、建议卡、预览徽标或装饰动画。真实项目归属可作为输入器上方的上下文行，行无可用内容时不占位；执行权限和活动计划状态位于输入器底部操作行。发送第一条消息后原输入器回到底部，不复制、销毁或重新创建 textarea。

### 消息

- 用户：靠右、主题浅表面、1px 边框；标准 12px 圆角，右上角 2px 消息尾部。
- 助手：无卡片、无头像，直接进入内容流。
- 正文默认 14px/24px，用户消息 14px/22px；外观设置仍可选择更大的聊天字号，行高随字号同步增加。标题使用 20/18/16/15/14/13px 层级。过程中的普通助手说明与最终回答共用正文字号，不放进 12px 工具详情卡；首尾内容块去除额外外边距，紧凑列表项不重复叠加段落间距。块级公式按文档正文排版，不另包边框卡片。
- 行内代码：4px 内容标记；代码块：12px 容器，语言、复制/下载、换行和长代码展开；完成态使用语言高亮，流式保持稳定文本和用户展开状态。
- Markdown 使用统一解析器，覆盖标准块/行内结构、链接、脚注和任务列表；模型原始 HTML 永远作为文本。表格可复制 Markdown、导出安全 CSV、放大；少于四列和引用内表格填满阅读列，多列表格保持可读列宽并在自身区域横向滚动，单元格用横向分隔线而非重复嵌套网格。
- `$…$`、`\\(…\\)`、`$$…$$`、`\\[…\\]` 和 math/latex/tex 围栏由 KaTeX 排版；Mermaid 使用隔离的实际引擎，结束后且进入阅读区域才绘制，支持源码/图表切换、放大和 SVG 导出。解析失败保留原文与重试，不显示不完整的猜测图。
- 表格、代码、数学与图表只在自身区域滚动或换行，不撑破聊天列。
- 多轮会话在聊天区左侧提供问题导航：基础刻度为 12×2px、槽高 10px，当前阅读项只加深；悬停或键盘聚焦形成 2.6 / 1.7 / 1.25 的邻近山峰。120ms 后显示贴近刻度右侧的 320px 预览，离开 80ms 后关闭；问题最多 2 行，回答最多 3 行。点击精确跳到对应用户输入，正常使用 smooth、减少动效时使用 auto。少于两条用户输入不显示，容器宽度低于 864px 隐藏；长列表在轨道内滚动并保持当前项可见。

### 阅读与内容操作

用户长正文折叠保留“展开全文”入口，复制使用完整原文；助手动作区只复制其对应回答原文，不混入隐藏的中间说明或工具日志。复制按钮使用有明确名称与提示的 28px 图标入口，成功/失败反馈不改变命中区域，不删除图标；连续点击只恢复当前反馈的原始状态。操作在 hover/键盘聚焦时出现，触控环境不依赖 hover。正文选区可填入主输入或旁支草稿，不直接执行。查找高亮按源文字偏移映射，不能因行内强调和 Unicode 大小写而错位；明确已加载轮数与继续搜索入口。

历史页向上追加保持锚点与已有消息节点；返回某会话恢复其阅读页，另有“返回最新对话”。内容增长、图片加载及面板宽度变化不得把上翻阅读者强拉到底；未跟随时提供“回到底部”。断线显示待确认状态与重新连接操作，不用任务失败或任务完成图标替代。 用户在异步加载期间改变阅读位置时，新位置优先于之前的加载锚点；在工具日志内部上翻不取消中央正文的跟随状态。关闭查找必须停止延迟高亮和导航，重新打开搜索不接收旧查询的迟到结果。

### Composer

标准输入器为 22px 圆角、1px 细边框，使用仅限主任务输入器的 `--ui-shadow-composer` 轻投影，不给 textarea 增加第二层外框或投影。上内边距 8px、正文左内边距 14px、正文 14px/24px，文本与操作行间距 12px。底部操作行参考 DSH InputBar：左侧 `+` 为 28×28px 圆形，文件权限触发器高 28px、13px/20px/500、14px 图标，权限菜单 16px 圆角、3px 内边距、单行至少 34px；活动“计划”按钮高 28px、14px 圆角，未进入计划模式时不存在视觉占位。右侧模型触发器高 28px并紧邻 34px 圆形发送按钮。窄列优先隐藏权限文字、缩短模型名或分行，保持真实交互高度。

`+` 命令菜单与主输入框同宽，顶部间隔 4px，视口边缘至少 12px，高度不超过 400px 及可用空间，超高时内部滚动；使用已有顶层浮层避免被输入器裁剪。菜单 16px 圆角、3px 内边距，组标题 11px/16px、至少 23px 高；每行 34px 高、14px 图标、13px/20px 名称、12px/18px 英文别名及右对齐说明。只渲染有真实贡献的分组；窄屏截断文字但保留完整可访问名称。Escape 返回 `+`，不清空草稿；会话切换、模块撤销或来源隐藏时关闭或刷新。该命令浮层复用 `--ui-shadow-hover-card`，不将阴影扩散至普通卡片。

草稿自动随内容增高，新任务正文起始 52px，已开始会话起始 36px，上限 220px；短屏额外为聊天保留可阅读空间，达到上限后仅文本区滚动。程序写入草稿、输入法、换肤和容器缩放均复用原 textarea，不改变选区或重发任务。滚轮处于输入器留白、或文本已到滚动边界时继续滚动会话，不形成无法滚动的底部区域。

输入器下方三组统计使用 12px 次要文字、14px 图标、28px 交互高度和等宽数字，保持单行与输入器对齐。可用宽度低于 440px 时收紧到 11px 并隐藏重复的缓存说明后缀，完整含义仍在可访问名称和详情中。统计入口不显示悬停提示；点击打开视口内可滚动的顶层说明面板，Escape 返回触发项，点击外部或父区域隐藏时关闭。未知值使用 `—`，不完整 Token 显示下界；上下文详情中的分项用 `~` 标记估算，圆环不是任务进度。默认隐藏纯键盘发送提示与统计的重复占位。

## 7. 执行过程

| 可见层 | 合同 |
| --- | --- |
| 外层摘要 | 32px，只显示本轮时间或停止/失败状态与相邻箭头，不重复过程组的当前命令；底部 1px 分隔线 |
| 活动行 | 28px，13px 文字，静止透明、hover 轻表面、8px hover 圆角 |
| 工具组 | 连续工具形成过程组，可见助手回复分隔组；标题显示实际当前工具或结束后的数量，图标与展开箭头共用位置；展开内容最大为 400px 与视口高度一半中的较小值 |
| 行标签 | 工具类别（终端 / 读取 / 搜索 / 写入），15px 线条图标 + 等宽命令摘要 |
| 详情面板 | 默认 8px 圆角、1px 边框、10×12px 左右量级内边距；只放 `$ 命令` 与输出，无标签与页脚 |
| 命令区域 | 最大约 132px，自身滚动 |
| 日志/结果 | 最大约 320px，自身滚动 |

组内滚动独立于整页：手动打开运行组定位最新活动，打开已结束组从开头阅读。上翻后新增工具不能拉回底部；历史前置保留阅读成员锚点。顶部/底部渐隐仅表示还有内容。详细模式的运行组、全部模式取消组标题和高度限制，但不搬移成员节点。标题最多按 150ms 的可读节奏合并更新；用户切换展示模式、失败和结束状态立即生效。

没有详情的活动项不是假折叠控件。失败、拒绝、取消和进行中必须可区分；完成状态不在每行重复写“完成”。 简洁/标准在运行时保留过程组摘要，详细直接显示运行组，全部显示所有过程；成功后的最终答案不折叠。失败、停止或有补充输入时不提供整轮隐藏。展开选择属于用户交互状态，不能因 Token 增量、模式切换或历史前置重置。

流式段落追加保留未改变的行内代码、强调文字和文件操作节点；路径或权限上下文改变时重新绑定，不复用过期回调。

工具结果可显示安全 Rich Content（内联图片与 Resource 描述）、统一 Artifact Viewer，以及 namespaced UI details。`coding.diff` 使用专用 Diff View，未知 detail 以折叠 JSON 安全回退；任意工具 `structured` 数据不直接进入浏览器。Artifact 只能通过宿主授权读取器分页读取，不把本机路径当作链接打开。

## 8. 设置页面

### Shell

- 左栏 232px，页面内容 gutter 32px。
- 设置标题 20px；导航高 36px；标题说明 13px。
- 内容最大宽度 1040px，阅读型页面可缩到 760px。

### Agent 组件与工具

- 组件与工具使用两个独立设置页，共用 12px 面板和 1px 边框。
- 清单只包含可由用户开关的可选项；固定基础项、最小必备项和部署锁定项不渲染。
- 行基线 72px；标题 14px，说明 12px，Switch 40×24px。
- 不显示“当前已启用”“可由当前用户管理”等常态标签；只有状态等待重启时显示 10px 的“重启后启用/停用”徽标。
- 内容允许自然增长，但不得通过固定 116px 行高制造空白。

### 模型供应商

- 左列 240px；搜索输入 36px；供应商行约 44px。
- 详情头基线 72px；标识 36px；名称 18px；操作 32px。
- 模型行最小 52px；包含上下文等第二行元信息时可自然增长到约 68px。模型名 13px，状态徽标 10px，默认操作 32px。
- 操作过多时使用明确菜单或换行，不缩小到不可点击。
- 供应商表单明确选择接口协议，详情头显示实际协议；原生推理参数使用折叠区，复用已有 textarea 样式，不在普通编辑时强制展开。
- 模型能力和最大输出使用折叠区；能力 Select 为支持/不支持/未知三态，默认未知。使用现有控件 Token，窄屏与 Dialog 自身滚动，不增加页面横向溢出。

### 记忆与历史原文

- 记忆管理是独立设置页，长期条目与历史搜索分区，不在会话列表中常驻大面板。空间选择使用共享 Select，条目正文 13px，来源与容量 12px。
- 编辑复用普通 Dialog、Textarea、保存/取消；冲突保留输入，不伪装保存成功。删除确认明确不同时删除旧会话。
- 原文按有界分页替换显示，支持相邻消息定位；正文可选择、换行并在区域内滚动，不累计整库内容。所有文本作为文本渲染，不执行历史 HTML 或指令。
- 窄屏按钮允许换行，页面不横向溢出。未装配、关闭、空内容、加载及错误状态与实际宿主一致。

### 外观

- 模式分段 32px；皮肤卡 12px 容器，缩略图 72px。
- 简单设置行 52px；Select 36px。
- 预览必须明确为预览，不能创建任务或伪装真实对话。

### 右侧工作面板

每个窗格使用独立的48px标签栏、28px标签和60–156px弹性标签宽度；全屏、概览、分栏、收起只出现一套28px图标按钮。活动标签滚入自身标签条的可见范围；方向键/Home/End移动焦点，Enter/Space激活，Alt+方向键排序，中键/Delete关闭。标签可移到另一窗格，关闭本窗格其他标签或全部标签；不增加重复的并看标题行。

右栏默认420px，偏好范围320–720px。三栏共同保护400px聊天列：先按可用空间缩小右栏，连320px右栏都放不下才进入独立浮层，不再采用固定1180px切换线。左右栏拖动或窗口缩放即时联动，恢复空间后还原原偏好宽度。创建第二窗格至少需要640px，已有分栏在退出全屏、收起或切换会话后保留；拖动和键盘调整立即更新横向／上下排列，不等待窗口再次缩放。分隔比例20–80%，横向窗格还保证240px最低操作宽度；分隔条支持拖动、方向键调整、双击/Enter均分。空窗格自动合并，最后一个标签关闭后收起面板并归还焦点。没有原生浮窗或无限嵌套布局入口。

文件树和文件预览均使用36px单行路径工具栏；复制、下载与换行放入文件菜单。菜单顶层定位并受视口约束，首次焦点只进入可见且可用的操作，Escape关闭菜单并返回触发项。分页复制明确标为“复制已加载文本”；完整文件大小在路径提示中，正文外只保留分页或错误等必要状态。代码行号与正文共用文档滚动区域；明确的行引用优先于源码／预览模式的阅读位置恢复，只滚动本文件并替换旧行高亮。iframe占满剩余高度。目录搜索保留浏览状态，过期结果不覆盖新查询；刷新失败保留已读内容和重试入口。 Office/完整二进制预览确认新内容可用后才替换旧版本；读取失败不能先清空已经显示的文档。表格、图片、图表放大视图与来源共同释放，切换来源页或关闭消息不能留下原内容的孤立弹窗。图片读取失败提供原位置重试，不触发 Agent 重新执行。

当前格式的文件布局仅保存有界路径、两窗格标签分组、活动项、比例和显示偏好。恢复必须重新鉴权，不保存正文、凭据、终端命令或旁支历史；内容DOM不因分栏、全屏或收起而重挂。UI模块的标签所有权和释放机制不受布局影响。详见[应用层接口](../architecture/WEB.zh-CN.md)。

## 9. 空态与反馈

- 空态：13px，说明当前状态和第一个可执行动作。
- Notice：12px；成功/错误使用语义前景，不改变布局。
- 状态徽标：10px，胶囊，仅承载短状态；长解释放正文。
- 加载不能用假内容占位冒充完成数据。

## 10. 响应式和验收

`≤1000px` 收窄侧栏和设置双栏；`≤680px` 主侧栏抽屉化、设置单列化。正式组件必须在 1440×1000、390×900、320×800 下保持可操作且无页面级横向溢出。

组件值有变化时，同步：

1. `apps/web/design-system.css`。
2. 本文件。
3. `scripts/check-web-design.mjs`（若合同需要新门禁）。
4. 对应单元测试与 `apps/web/test/design-system-e2e.mjs`。

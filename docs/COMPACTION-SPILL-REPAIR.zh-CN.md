# Compaction / Spill 审计修复记录

日期：2026-09-22。状态：修复及必要本地回归通过。范围：修复本轮审计发现的行为缺口，保留已有默认装配策略和其他任务的改动。

## 修复内容

| 审计问题 | 修复方式 | 必要验证 |
|---|---|---|
| 一条用户请求后的多轮工具历史全部被保护，超限前摘要调用为零 | 固定保留最新用户消息、系统约束和不可压缩内容，允许压缩其后的旧工具组；工具调用/结果不可拆分 | 单条请求完成七轮工具调用，各工具只执行一次，所有模型请求在预算内 |
| 摘要可能扩大历史，60% 目标没有可靠落实 | 在真正压缩后的投影上计算压力；成功必须缩小并低于触发阈值；给摘要预留明确字节预算并校验完整结果 | 过大的摘要被拒绝，不发起下一次主模型调用 |
| 读取归档忽略 Run 结果上限 | `spill_read` 和正式宿主 `read` 扩展都计入文本、完整 metadata、artifact 的实际开销，自动缩小返回页 | 512 字节结果上限下请求 2048 字节，仍能持续分页读取 |
| UTF-8 页会超过请求 limit 或跳过字符 | 定位读取有限字节，要求 offset 对齐；容不下一个字符时返回明确错误 | 多字节分界和 1 字节页限制 |
| 终态观察事件丢失导致不清理 | 执行器等待变换器 `finish(run_id)` 后才发布终态；正常、取消、错误路径均执行；清理失败进入报告 | 十个快速完成的 Run 调用十次清理；其他 Run 结束不释放活动归档保护；取消释放保护 |
| 摘要缓存没有随任务结束释放 | Compactor 的 `finish` 移除单 Run 缓存，宿主关闭清空剩余状态 | 缓存复用后收尾释放 |
| Windows 私有目录依赖已有 ACL | 在本地后端落实并验证私有权限，权限设置失败不能伪装提交成功；权限辅助进程有截止时间和取消清理 | 核验根目录、Run 目录及归档文件实际 ACL |

## 契约与边界

`ContextTransform`、`ResultTransform` 的 `finish` 有默认空实现，现有实现无需新增方法。收尾发生在工具结算之后、终态检查点和报告发布之前。每项使用独立于 Run 取消的 `hook_timeout`；失败后继续调用其余收尾，不重试工具。直接使用变换器 API 的宿主也必须在操作停止后调用收尾。

Compaction 继续使用规范化请求字节预算，不宣称精确 token 计量。默认目标 60%；当必须保留的最近完整组自身过大时，允许无法达到 60%，但仍要求成功结果严格低于 80% 且确实缩小。不能满足条件则明确失败。摘要请求按完整组装包并计入 JSON 转义和模型选项，调用次数受原任务预算约束。

Spill 继续是有限保留的本地归档：在写入前、Run 收尾和宿主启动时惰性清理已过期的非活动文件，不承诺精确定时删除。取消、超时或存储失败不会重放业务动作。

## 组合验收

`apps/server/src/spill_flow_tests.rs` 使用真实 HTTP、Chat 模型适配器、Runtime、Application、Spill、正式 `read` 扩展与 Compaction；供应商端为明确的本地测试端点。

同一次任务完成六次有副作用工具调用、归档、多页读取、上下文压缩和最终回复，核对工具次数及原文一致性。随后通过带 Bearer 的宿主归档接口分页取回原文，未授权读取被拒绝。测试工具只存在于测试代码，不注册到正式默认组合。

测试仅覆盖本次修复直接涉及的回归与这一条组合链路，不重复跑未受影响的 UI、模型管理或全工作区测试。真实供应商、生产负载与其他平台的运行验收不由本轮本地测试代替。

# 设计决策记录

| 编号 | 决策 | 理由 | 代价／后续 |
|---|---|---|---|
| ADR-001 | Core 以 Rust 库交付，不默认起服务 | 可被桌面、Web、CLI 复用 | 远程调用需独立 server 应用 |
| ADR-002 | 三个基础包，插件只依赖 API | 稳定依赖方向，避免内部耦合 | 需要显式的协议类型 |
| ADR-003 | 默认 ReAct 基座 + 小型插件宿主 | 借鉴 Pi 执行边界与 DSH 装配思路 | 不实现完整 Cordis |
| ADR-004 | 原生插件编译期链接、启动期装配 | 最小部署成本和清晰类型边界 | 新增插件通常需要重新编译 |
| ADR-005 | 不直接加载 Rust 动态库 | 避免 ABI、版本及资源隔离复杂度 | 动态分发需求另立进程/WASM 方案 |
| ADR-006 | 每个 Run 一个主要状态拥有者 | 状态提交明确、避免大共享锁 | 插件只能返回投影或决策 |
| ADR-007 | 记录与模型输入投影分开 | 记忆/压缩不修改运行事实 | 审计和克隆产生有界额外内存 |
| ADR-008 | 默认无自动重试 | 避免断流/超时后重复副作用 | 可用性上作保守取舍 |
| ADR-009 | 写工具默认拒绝，策略只能收紧 | 稳定的最终执行关口 | 业务需显式授权/审批 |
| ADR-010 | 合作式取消 + Unknown | 不伪装已撤销外部动作 | 真实工具需管理进程和幂等恢复 |
| ADR-011 | 源顺序提交、并行安全组 + 独占屏障 | 兼顾并发和执行含义 | 不自动解决跨 Run 工作区竞争 |
| ADR-012 | 有界观察流 + 独立最终结果 | 慢 UI 不阻塞 Agent，不无限缓存 | 观察器必须接受 lag；非耐久 |
| ADR-013 | 统一受预算约束的模型网关 | 插件辅助调用不重置预算 | 原生可信代码仍可能主动绕开，非安全沙箱 |
| ADR-014 | Planner 放在 AgentExecutor 上层 | 不复制循环/工具/模型实现 | v0.1 没有自动重新规划 |
| ADR-015 | Memory 示例显式写入且仅内存 | 避免默认隐私持久化与外部依赖 | 不是长期记忆产品 |
| ADR-016 | 长结果默认有标记截断 | 最小且明确的资源边界 | 归档、分页、reducer 后续扩展 |
| ADR-017 | Schema 复用成熟库，注册时编译 | 不自造参数校验器 | 依赖与 schema 版本需锁定 |
| ADR-018 | 原始 Rust 源码未编译也必须明确标注 | 防止把设计和测试文件当成验收结果 | 本包是待编译候选版 |
| ADR-019 | 不硬限制代码行数 | 可维护、明确错误路径更重要 | 格式化后行数可能明显增加 |
| ADR-020 | 协议号与包版本分开 | 插件接入时明确兼容性检查 | 0.x API 仍需管理破坏性变更 |

任何变更如放宽权限、增加自动重试、改变结束条件、把观察事件变成关键事务，均需新增 ADR、回归测试并更新架构文档。


## v0.2 新增决策

| 编号 | 决策 | 取舍 |
|---|---|---|
| ADR-021 | 公共AgentRuntime/RunSession支持完整流式控制 | 库调用不再绑默认Engine；API破坏性升级到2 |
| ADR-022 | Application是独立可选门面 | 统一任务/回放/幂等；CLI可不使用 |
| ADR-023 | 两个桥接分别编译、只依赖Application/API | 组合根选用；不强制HTTP服务进入Tauri |
| ADR-024 | Codex-inspired item生命周期，不做wire兼容 | 保留可用显示语义，不承诺完整Codex产品 |
| ADR-025 | 权威完成项覆盖增量 | 避免重复拼接，UI须识别有界预览 |
| ADR-026 | 内存journal过期明确快照恢复 | 资源有界，不能用于掉电恢复 |
| ADR-027 | Tauri每包ACK，订阅与任务独立 | 慢客户端可能失去中间动画，但不无界积压 |
| ADR-028 | 暴露UI安全投影，不透传RunReport | 不主动泄露系统/审计/隐藏协议字段；工具内容仍需治理 |
| ADR-029 | 可信权限域一份Application | 本版不是多租户服务平台 |
| ADR-030 | JEV不进入本次核心 | 按用户明确决定，避免未验证的提前抽象 |
| ADR-031 | 窗口内幂等而非永久exactly-once | 重启/forget/过期后由业务承担持久化幂等 |
| ADR-032 | Tauri原生feature单独验收 | headless通道测试不冒充桌面联调 |


## v0.3 新增决策

| 编号 | 决策 | 取舍 |
|---|---|---|
| ADR-033 | 只从Mona提炼四类通用契约，不迁入业务模块 | Mona适配仍需独立完成 |
| ADR-034 | Content支持字符串和有序内容块，ToolOutput区分已知错误 | Rust接口升级；默认文本用法保持简单 |
| ADR-035 | Run工具上限+每轮单调收紧选择，注册表不热改 | 动态安装能力留给宿主 |
| ADR-036 | 可选单一CheckpointSink，确认失败停止 | 有存储IO成本，不实现DB/恢复/exactly-once |
| ADR-037 | 派发前intent、局部结果和终态分别确认 | intent不等于已执行；外部恢复不得盲目重放 |
| ADR-038 | 结算提交使用独立的短期取消令牌 | 停止后仍可记录终态，关闭可能等待多个提交 |
| ADR-039 | ProviderData完整快照、命名空间、白名单 | JSON语义保真，不承诺原始HTTP字节和跨模型兼容 |
| ADR-040 | 模型工具结果与UI DTO分离，UI协议保持2 | 图片卡片和附件上传留给应用 |
| ADR-041 | 超限富结果明确失败，不剪碎媒体 | 应用需设置媒体预算或归档/缩放 |
| ADR-042 | 公共ModelOptions继承默认值，凭据/端点仍为宿主配置 | 不做自动模型路由和参数能力发现 |
| ADR-043 | 组件按 `packages/` 组织并使用短命名，Plugin 作为可选薄入口；正式应用放 `apps/`，样例放 `examples/` | 能力可由普通 API 直接使用，宿主按需组合；源码包名迁移与 Tauri `bridge` namespace 同步，执行流程、任务 payload 和 UI stream v2 不变 |

# 安全与部署边界

## 必须保留的约束

- 模型请求工具不等于已授权。参数完整、Schema、插件否决策略和宿主副作用授权之后才执行。
- 工具取消/超时只表示不能继续等，不代表外部操作撤销。Unknown 必须保持可见，不自动重试有副作用操作。
- 可选桥接不允许客户端覆盖 system prompt、模型配置、执行上限或工具权限。一个 Application 是一个可信权限域。
- 请求审计、完整Transcript、provider reasoning_content 不经公共桥接返回。公开工具内容仍由工具/输出变换器负责敏感数据治理。
- 流式字符串和结构化详情都是不可信数据。前端使用文本节点或有清理策略的Markdown渲染器；不执行HTML/JS，不自动打开Artifact URI。

## HTTP

示例只环回监听，无默认token。远程部署要求 TLS、真实身份认证、租户/权限域路由、请求限流与日志审查。CORS只限制浏览器读取，不代替认证；随机token不是完整用户管理。

本版没有持久化身份、每用户额度、反向代理配置或多实例分布式journal。token应通过可信配置注入，不放浏览器持久存储、URL查询或错误日志；前端的密钥管理由业务决定。

## Tauri

只将插件capability授予可信本地界面，配合CSP，禁止任意远程网页获得同一IPC能力。WebView label 来自Tauri原生注入，不接受前端自称owner。label白名单不是XSS防护，受信任界面被注入后仍可能调用获准能力。

ACK限制传输堆积；超时是可用性机制，不是恶意代码沙箱。不要把本地Rust插件看作受隔离代码，它仍可直接访问文件/网络/线程。

## 回放/持久化

journal、任务键和UI快照只在内存。重启后无法恢复工具实际完成状态，不提供 exactly-once。TTL 和 forget 结束幂等窗口，因此业务不可重复写入仍需后端幂等键与核查。

删除注册表项不能撤回调用者已经持有的数据；取消信号也不能撤回已经发出的请求。敏感数据清理与可审计持久化须另行设计。

## 可用性和资源

任务、订阅、日志和预览都有上限。慢消费可能收到替换快照，UI需容忍中间动画缺失。Tauri每包ACK必须尽快完成；长期阻塞JS时先退出订阅，再用游标/快照恢复。

还未执行真实Rust编译、原生Tauri联调、生产压力测试和安全审计。本包不能凭“使用Rust”或“参考Codex”就自动取得生产安全保证。


## v0.3 新增风险边界

- 图片Base64校验不是图片解码、安全扫描或大小预算替代；远程图片URL可能由Provider访问，需要宿主控制可访问资源。
- ProviderData不进默认UI，但存在可信消息/审计/检查点中；持久化端必须处理隐私和访问控制。普通文本/参数/显式附件仍需业务脱敏。
- ToolSelector不是授权器；模型请求之外的工具名也在执行前拒绝。选择器不能扩大Run上限或前一个选择器的输出。
- 配置持久化后，关键commit失败禁止继续正常流程；已发生副作用不可回滚。不要从intent记录推断安全重试。
- CheckpointSink是可信同进程代码，不是沙箱，也不是扣款/业务操作接口。它需声明成功条件、事务、幂等、保留与加密；内存示例不提供掉电恢复。
- generation provider_options不能覆盖工具/令牌限制/凭据/端点；外部适配器也必须遵守同样边界，不能因类型是JSON就任意透传所有字段。

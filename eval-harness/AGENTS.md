# 测评工程开发规则

- 本目录为独立子项目，不依赖父仓库包、Web 资源或私有类型；不要为接入测评修改 Agent Core。
- 通用逻辑与被测 Agent 分开。Mona 特有行为仅在 adapters/mona.py；接入其他 Agent 使用公开 adapter 协议。
- 夹具、自检、真实模型评测必须明确区分；缺失观测标记 unknown，不写成零，不把跳过算通过。
- 调用者显式授权才运行模型和本机可执行程序。凭据只来自宿主环境，不返回浏览器或写入报告。
- 任务目录、状态目录按 trial 隔离；本机进程隔离不是安全沙箱。不接受未经审核的任务代码或恶意 Agent。
- 参考答案和评分规则不传给 Agent；评分依据结果和可观测事实，不相信 Agent 自报成功。
- 保存报告后再发布完成状态；重启将未完成评测标为 interrupted，不自动重放。取消只清理自有进程。
- README 介绍使用；docs 仅保存当前架构和 adapter/任务契约；运行数据与验收记录位于忽略的 .local/。
- 修改后运行 python -m unittest discover -s tests -v，Web 变更还需真实浏览器验证。未经授权不提交或推送。

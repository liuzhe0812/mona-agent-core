# Mona Agent Web UI

这是 Mona Agent Core 的正式通用 Web UI。它使用与 HTTP Bridge / Tauri Bridge 相同的流式工作项协议，但本身不实现 Agent Runtime。

视觉规范见 [UI 设计规范](../../docs/ui/DESIGN.zh-CN.md)。正式页面由 Mona 自有 `design-system.css` 管理 Token，`content-renderer.mjs` 负责安全内容展示。助手正文支持标题、强调/删除线、转义、行内代码、任务/嵌套列表、表格、引用、分隔线、显式与自动链接；围栏代码显示语言、复制、基础语法高亮，长代码可展开。数学支持 `$…$`、`$$…$$` 及 math/latex/tex 围栏并生成 MathML；Mermaid 围栏内建支持 flowchart/graph，其他语法安全退回源码块。模型输出永远不会作为 HTML 执行。流式回答按短时间窗口合并刷新，并只替换发生变化后的 Markdown 尾部，已经稳定的前缀 DOM（包括代码操作状态）不重建。执行过程按真实事件顺序展示中间文本和工具；工具详情支持安全 Rich Content、内联 Base64 图片、Resource 描述、统一 Artifact Viewer、`coding.diff` 专用 Diff View 与未知 UI detail 的折叠 JSON 回退。远程图片 URL、路径型 Resource locator 和任意 `ToolResult.structured` 不回传浏览器；只有无路径 opaque Artifact 引用可进入页面，并且仍只经宿主鉴权分页读取。终端输出显示前移除 ANSI 控制序列。当前协议没有独立思考事件，因此不生成虚构思考内容。

## 一键连接真实 Runtime

在仓库根目录直接运行：

```sh
npm run dev:web
```

启动器会同时启动：

- Rust `server`：真实模型模式，默认 `127.0.0.1:8787`。
- Web UI Server：默认 `127.0.0.1:4173`。
- 浏览器中的 UI 会自动使用 HTTP/SSE Bridge 连接，不需要手工复制 Bridge Token。

无需 `.env` 或 `npm install`。最终用户分别通过“设置 → Agent 组件”和“设置 → Agent 工具”管理可选装配项，通过“模型设置”添加供应商；未配置模型时不会退回假模型。完整说明见 [本地开发文档](../../docs/DEVELOPMENT.zh-CN.md)。

## 模型窗口与项目上下文

模型列表中的“上下文窗口”可设置具体供应商/模型的 token 容量，新增模型时也可填写；未知保持空值。保存及发现模型不会丢失已有容量，改变只影响新任务。窗口估算、输出预留和字节硬限制由后端处理，界面不自己计算或伪造容量。

“设置 → Agent 组件 → 项目规则”控制工作空间 AGENTS.md/CLAUDE.md 自动加载，内置默认开启，切换后下次启动生效。长会话会复用已保存的工作摘要；历史页仍展示原始消息。同会话旧 Spill 文件经归属验证后可读取，过期或删除会明确提示。实现与限制见[上下文管理](../../docs/CONTEXT-MANAGEMENT.zh-CN.md)。

## 设计系统

正式 Web UI 已统一接入 Mona 设计系统：普通按钮/输入默认 36px，紧凑操作 32px；设置侧栏 232px、桌面内容边距 32px、页面标题 20px；组件与工具设置行按内容紧凑呈现，供应商头部和模型列表使用统一行高。容器默认 12px，内层控件 8px，普通动作与单行输入使用胶囊形；基础页面不使用装饰阴影。

实现分层：`design-system.css` 维护基础、语义和组件 Token，`styles.css`、`sessions.css`、`appearance.css` 只描述各自 surface。正式范围和历史预览边界见[生产界面台账](../../docs/ui/DESIGN-INVENTORY.zh-CN.md)，具体尺寸见[组件合同](../../docs/ui/COMPONENTS.zh-CN.md)，变更流程见[设计治理](../../docs/ui/DESIGN-GOVERNANCE.zh-CN.md)。

```sh
npm run check:web:design
npm run test:web
npm run test:web:design
```

静态门禁禁止正式 feature CSS 新增裸颜色、任意字号/字重/圆角、硬编码动效时长和普通投影，也限制运行时 JS 只能使用已登记的侧栏宽度、主题变量和菜单坐标钩子；真实浏览器检查覆盖主工作区、三类设置、Dialog、浅深色、聊天和 390/320px。

## 主题与皮肤

入口为“设置 → 外观”。提供石墨、海盐蓝、松林绿、鸢尾紫、暖砂、蔷薇六套皮肤，每套都有浅色和深色配色，并可跟随系统。消息普通正文可选 14/15/16/18px，面板圆角可选标准、柔和、利落；标准档遵循 12px 容器/气泡/输入器和 8px 详情内层。

选择即保存并生效。外观只保存在当前浏览器、当前站点的 `localStorage`，同站点标签页同步；刷新和浏览器重启可恢复。保存失败保留旧外观并显示错误，读取到损坏数据时回退默认但不静默覆盖旧数据。换肤只更新样式，不清空草稿、不重建聊天节点、不重连或重跑任务。

可导出当前皮肤的浅/深色配色，也可导入最多 32 KiB 的 Mona JSON 皮肤。自定义皮肤仅保留一个槽位，再次导入会替换；恢复默认保留已导入皮肤。导入校验字段、版本、颜色和基本对比度，不接受脚本、任意 CSS 或外部图片。预览区明确是样式样本，不触发 Agent。

实现仅位于 `apps/web/`，不使用 Rust Plugin，也不新增宿主接口。首版不包含背景图上传、跨设备同步或主题市场。文件格式、职责边界和验证方式见[主题系统](../../docs/ui/THEMES.zh-CN.md)。

## 本地会话

正式 HTTP 宿主默认将会话存入本机用户目录。左侧按任务列出本地会话，支持分页、重命名和删除；搜索位于 Mona 标题右侧的按钮（或 `Ctrl+K`）打开的弹窗中，由宿主按名称查询，不在侧栏常驻输入框。打开历史后继续发送，会从宿主读取可信消息上下文，不是仅在页面上拼接旧文本。新建任务不会继承其他任务历史。

侧栏只承担任务导航：品牌与搜索入口、新建任务、任务列表、底部设置。当前版本没有工作区与项目分组，因此不显示工作区标签、项目分组或与顶栏重复的“当前任务”行。侧栏宽度可以拖动右边界调整，也可以 Tab 聚焦分隔条后用左右方向键调整，范围 208–460px，结果只保存在当前浏览器；窄屏下侧栏是抽屉，不提供拖拽，收起时隐藏分隔条。

任务列表平时显示标题与相对时间，任务行常驻图标占位：正在执行的任务在占位里显示持续转动的指示（减少动效下仍转动，因为它承载状态），任务结束后占位保留、标题位置不变。行右侧只有一个位置：相对时间与行内操作（置顶与 `⋯`）占同一个盒子、右边缘对齐，静止显示时间，悬停或键盘聚焦时原地互换，两者互斥且标题宽度不变。`⋯` 与右键打开同一个任务菜单，每项都带线条图标：重命名任务、置顶聊天/取消置顶、归档/取消归档、标记为未读/标记为已读、删除任务（最后一项、危险色）；置顶与归档由宿主持久化，置顶排到列表最前，归档把任务移出当前列表且可由已归档视图恢复。未读任务在图标占位里显示圆点，打开该任务即清除标记。生成分享链接这类宿主没有的能力不出现在菜单里。分组标题悬停显示 `⋯` 与新建任务：`⋯` 菜单提供刷新列表和显示/隐藏已归档任务，因此归档可以恢复；分组折叠箭头只改变本地显示，并记在本浏览器。当前宿主未提供的操作（如标记为未读）不出现在任何菜单里。

刷新或重启会恢复已确认的消息与工具结果；异常中断有明确状态，不自动重跑模型或工具。尚未确认的流式片段及瞬时进度不保证保存。数据不放在浏览器 localStorage，完整设计、存储位置及安全边界见 [本地会话](../../docs/LOCAL-SESSIONS.zh-CN.md)。

## 单独使用界面

标准入口是 [index.html](index.html)。它使用原生 ES Module，因此需要通过 HTTP Server 或 Tauri WebView 加载，不能依赖 `file://` 直接双击。它包含连接设置：

- Web / 远程场景选择 HTTP Bridge。
- Tauri 宿主选择 Tauri Bridge，不需要本地 HTTP Server。
- `npm run dev:web` 会在开发环境自动完成 HTTP 连接。

## 与 Core 的边界

```text
Web UI
  -> JavaScript AgentClient / RunView
  -> HTTP 或 Tauri Bridge
  -> AgentApplication
  -> Agent Core
```

UI 负责渲染文本增量、工具工作项、最终状态和取消操作；Core 负责 ReAct、模型、工具、权限、取消和资源限制。关闭订阅不等于取消任务，停止按钮必须调用独立的 cancel 接口。

## 当前交付边界

- 正式通用界面通过独立的宿主会话接口打开持久历史；不在前端维护 Session 数据库，也不包含产品账号或多租户权限系统。
- 模型设置通过独立的 HTTP 管理接口工作；页面可以提交用户新输入的凭据，但已保存的模型密钥不会返回浏览器，也不会写入 `localStorage`。浏览器拿到的是本机开发 Bridge Token。
- “Agent 组件”和“Agent 工具”是两个独立设置页，只展示宿主已编译且允许用户开关的项目；固定基础项、最小必备项和部署锁定项不显示。只有变更确实等待重启时才显示“重启后启用/停用”。
- 上下文压缩和长结果归档在正式 Web 组合中默认开启，达到阈值才工作；Skills 默认关闭。Artifact Viewer 通过经过鉴权的同 Run/同会话接口分页读取文本归档；Rich Content 只显示安全 UI 投影，不把本机路径、远程私有 URL、任意 structured 数据或 HTML 执行能力暴露给页面。
- Tauri Bridge 当前只支持临时任务；会话区和模型设置页会如实提示宿主尚未接入对应管理接口，不宣称具备本地会话恢复。
- 直接部署到公网前，需要把这套模块化 UI 纳入正式前端构建与认证体系。
- 当前仓库未把 UI 发布为 npm 包；调用协议客户端位于 `packages/client/`。
